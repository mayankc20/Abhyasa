# Abhyāsa

A personal sadhana journal for the phone: wake time, mangala arati, 16 rounds, hearing and reading notes, service, research time, a 4-quadrant day plan, weekly targets, one Bhagavad-gītā verse at a time, and a password-locked private journal.

Everything is stored on the phone (IndexedDB). The private journal is encrypted with your password and cannot be recovered without it. Back up from Settings now and then.

## Install
1. Open the GitHub Pages link in your phone's browser (Safari on iPhone, Chrome on Android).
2. Share → **Add to Home Screen** (iPhone) or menu → **Install app** (Android).
3. Open Abhyāsa → gear icon → paste a Claude API key from console.anthropic.com so dictated notes get turned into cards.

No build step: the files in this repo are the app.

Gītā text: Prabhupāda's translations via [vedicscriptures/bhagavad-gita-data](https://github.com/vedicscriptures/bhagavad-gita-data).
